# SPEC-13 · AI 自由画布（思维导图 + 流程图）

- 状态：**待验收**（2026-10-12 施工完成；[自动] 过，[人工] B1~B3 待冒烟）
- 依赖：SPEC-04（导图 Tab）、SPEC-03（大纲章节作为素材）
- 验收 tag：`spec-13-accepted`

## 1. 用户决策（2026-10-12）

- 导图不再强制"节点可点击跳播"——充分发挥 AI 的组织能力，不设计那么多规则限制
- 「时间轴」→ 有层次的思维导图（按知识逻辑分组），不再按章节×时刻树状堆砌
- 「流程图」→ 自由度很高的画布，LLM 自己决定形态（分支/循环/子图/汇合），不再是固定的阶段列+概念行版式
- 判断确认：跳播锚定要求每个节点带时间戳并按章节排布，正是旧流程图死板的根源

## 2. 方案

- **核心 `core/pipeline/freeCanvas.ts`**（纯函数）：素材构建（章节标题/摘要/要点/术语，**刻意不带时间戳**防止模型回到按时刻堆砌）、围栏提取、导图 Markdown 归一（补根/多根降级）、Mermaid 归一（去 init 指令）、Zod 结构校验、单调用 + 一次纠错重试（错误信息回灌）
- **Prompt**：`canvas-mindmap.md` / `canvas-flowchart.md` 1.0.0——只写目标、自由度与语法硬约束，**不放可被抄写的示例列表**（0.7.x 教训）
- **渲染**：思维导图 = markmap（层级 Markdown，可折叠缩放）；流程图 = mermaid（securityLevel strict，滚轮缩放 + 拖拽平移 + 适配按钮，点阵画布背景）
- **校验**：流程图走 mermaid.parse 渲染器级校验，失败把解析错误回灌模型重试一次（红线 4 精神）
- **缓存**：`canvas::{kind}::{videoId}::{promptVersion}::{model}`，与旧 concept:: 隔离
- **保留**：「概念图」视图不变（旧结构化数据的唯一消费者，仍支持跳播）

## 3. 验收

- [A] free-canvas 12 例（素材无时间戳 / 围栏 / 归一 / Schema / 重试回灌 / 不无限重试）；mindmap-tab 3 例改写；1130 例全绿；CSP 扫描构建产物零 eval
- [B1] 思维导图：同一视频生成后呈现按知识板块分组的多层结构（非章节平铺）
- [B2] 流程图：形态随内容变化（有分支/循环/子图），缩放拖拽流畅
- [B3] 弱模型（qwen3.5-flash）语法错误时自动修正一次，仍失败显示原因 + 重试
