## 2. 目标结构

```
AGENTS.md                          ← 蒸馏宪法 + 检索规则（双节；扩展权威维护：存入时无则创建、有则覆盖）
_meta/index.json                   ← 机器索引：只索引蒸馏层（raw 不进索引——口径风险，质量在蒸馏层兜住）
索引/MOC-{领域}.md                  ← 人类目录：每领域一张（Obsidian 双链汇聚）
raw/{领域}/{课程}/BVxx.md           ← 字幕原文：行级 [mm:ss](回放URL) 锚点，只读永不修改
笔记/{领域}/{课程}/{标题}.md         ← 视频笔记：章节蒸馏（强制 ## 结构）+ vsc:notes 用户笔记区块
概念/{领域}/{概念名}.md             ← 概念页 = 术语表节点（五字段 frontmatter）
问答/{领域}/{课程}/Q-{slug}.md      ← QA 沉淀（手动）
```

## 3. 设计原则

1. **原料只读**：raw 永不修改；蒸馏页全部指回 raw（溯源终点）
2. **一切可溯源**：蒸馏页 frontmatter 带 source（bvid/时间区间）；结论句尾 `[mm:ss](回放URL)`
3. **蒸馏可生长**：同一概念聚合进既有概念页（追加式合并，手写保留），不新建重复页
4. **双索引**：机器读 `_meta/index.json`（检索性能不降）；人读 MOC + Obsidian 图谱
5. **人机分界**：vsc:notes 区块 = 用户手写保险区，AI 永不进入

## 4. 概念页 = 术语表节点（KM《入库前的秩序》五字段）

frontmatter：
- `preferred`：首选术语，全局唯一，**文件名 = preferred**
- `aliases`：各来源旧表述（**只增不删**——删除会毁掉历史条目可检索性）
- `broader`：上位概念（嵌套标签 `#领域/子域` 同步承载，支撑检索粒度伸缩）
- `scope`：适用范围（防跨领域过度泛化）
正文：
- 定义（划界式：区分邻近概念）用 `> [!note] AI 蒸馏 · 待核验` callout（人改写后该段自动免标——AI 不碰改过的段落）
- 引用记录：每条带**原句语境**（blockquote + 回放锚点 + source 标注）——"以什么身份连"决定检索跳转方向
  - `source: raw`（原句溯源，AI 蒸馏）
  - `source: user-note`（用户批注，已核验，检索加权 > AI 蒸馏）

**可逆性原则**（写进蒸馏宪法）：蒸馏产出的每个概念必须落位到概念页（新建或合并到既有），不得凭空自造表述。术语归一**不得后置**（入库后补救成本非线性爆炸）。

## 5. 蒸馏（Ingest）

- 新 prompt `distill.md` + Zod schema：输入=视频笔记（章节/要点/术语）+ 用户笔记与讨论串 + meta；输出=`{ domain, concepts: [{name(preferred), aliases[], definition(划界), broader?, anchorSec, sourceExcerpt(原句)}] }`
- domain：领域目录名（逻辑学/编程/考研数学…），模型判定，**新领域自动建目录**；用户可在 frontmatter 改
- 存入流程：蒸馏 → raw 落盘（规范化）→ 笔记落盘（领域化路径）→ 概念页逐个聚合（追加式）→ AGENTS.md 覆盖 → MOC 更新 → index.json 更新
- 失败降级：domain 回落 `通用`、概念页跳过、笔记原样落盘
- 讨论串：self 追问=用户批注（source: user-note）；assistant 回答=AI 生成（待核验）；蒸馏输入含讨论串

## 6. 检索（Query，扩展内统一通道）

- 所有消费方（问答检索/大纲上下文）统一走知识库检索 skill
- 升级：命中笔记时 frontmatter 的**概念链接内联返回**（related 链，一条链路抵三次重搜）
- 用户批注命中加权 > AI 蒸馏
- raw 不参与检索（BM25/文本匹配都不进）——只做溯源

## 7. AGENTS.md 双节宪法（扩展权威维护）

**A. 蒸馏宪法**：目录契约/命名规范/## 强制结构/术语归一（可逆性原则）/来源标注（source: raw | user-note）/用户笔记避让（vsc:notes 区块禁入）/待核验标记规则
**B. 检索规则**：先查库再答/术语经 aliases 映射/答案必须带溯源锚点/概念页跳转优先原文回放
**C. 位置**：知识库根目录——脱离扩展的其他 agent 读库有规则可循

## 8. Lint（体检）

- 入口：存入时增量 + 手动「知识库体检」
- 检查项：孤儿概念页（无引用记录）、断链、未归位术语、待核验清单（从未被人看过的 AI 概念页）
- v1 轻量：清单展示，不自动修复

## 9. 用户批注（第三类数据）

非 raw 非 AI 蒸馏，优先级最高。三铁律：不改写/不覆盖/不参与蒸馏合并；天然已核验（冲突以用户笔记为准并在概念页标注分歧）；蒸馏输入包含它但引用必须标 `source: user-note`。
