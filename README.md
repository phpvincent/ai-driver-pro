# 视频学习副驾（video-study-copilot）

B 站教学视频的 AI 学习侧边栏：字幕 → 章节大纲 → 知识流程图 → 随时提问 → 沉淀笔记。
为「看不懂、跟不上、记不住、找不着」设计，不是又一款"视频总结工具"——所有内容都锚定到**秒级时间戳**，随时跳回视频原位。

- 大纲/要点/概念/笔记全部可点击跳播到视频对应位置
- 卡住就问：划词解释、区间问答、自由追问（带多轮记忆），支持贴题目截图
- 笔记挂在大纲任意位置（整章/要点/时间点），可一键「请助教回答」变成讨论串
- 沉淀到 Obsidian，或一键下载 .md（自带来源与标签，放进任何笔记软件都能用）
- 大纲+笔记可导出为文件分享，别人一键导入

## 快速上手（三步）

### ① 配置模型（只做一次，约 3 分钟）

本扩展自带模型，需要你自己的 API Key（按 token 计费，一集 30 分钟视频的全部功能通常不到 0.1 元）：

| 服务商 | 适合 | 步骤 |
|---|---|---|
| [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) | 便宜、快 | 注册 → 充值（1 元起）→ 创建 API Key |
| [阿里云百炼](https://bailian.console.aliyun.com/?apiKey=1) | 多模态（能看课程画面/题目图） | 注册 → 开通 → 创建 API Key（新用户通常有免费额度） |

拿到 Key 后：扩展「设置 → 模型配置」粘贴 Key → 点「测试连接」→「保存」。
想看课程画面（PPT/代码演示）或贴题目截图，选 Qwen 系多模态模型。

### ② 打开一个 B 站教学视频

字幕自动加载：UP 主字幕优先，无则用平台 AI 字幕（需登录 B 站），都没有可手动粘贴文稿。

### ③ 生成大纲 → 看导图 → 随时提问

顶部 Tab：**字幕 / 大纲 / 导图 / 问答**。右上角「**？**」随时打开使用帮助。

## 安装

**方式一：Chrome 商店**（上架后推荐）——搜「视频学习副驾」一键安装，无需任何配置文件。

**方式二：免构建安装（推荐给不想碰命令行的用户）**：

1. 到 [Releases 页面](https://github.com/phpvincent/ai-driver-pro/releases) 下载最新的 `ai-driver-pro-*.zip` 并解压
2. Chrome 打开 `chrome://extensions` → 开启右上角「开发者模式」→「加载已解压的扩展程序」→ 选择**解压出来的文件夹**
3. 打开任意 B 站视频，点击浏览器工具栏图标唤出侧边栏

**方式三：从源码构建（面向开发者）**——仓库里是源代码，不含构建产物，需要 Node.js：

```bash
npm install && npm run build   # 构建产物在 dist/，加载方式同上
```

> 说明：为什么源码不能直接加载？扩展的界面代码用 React/TypeScript 编写，需要「编译」成浏览器能直接运行的 JavaScript（`npm run build` 做的就是这件事）。普通用户请直接用方式二，完全不需要安装 Node.js。

## 隐私与数据

**本扩展不设账号、没有服务器、不上传你的任何数据。**

| 数据 | 存在哪 | 谁能看到 |
|---|---|---|
| 字幕、大纲、导图、笔记、问答历史 | 你本机浏览器的 IndexedDB | 只有你 |
| 模型请求（字幕片段/课程画面/你的提问） | 用**你自己的** API Key 直连你选定的模型服务商 | 该服务商（与你在其官网直接使用无差别） |
| 公开资料检索 | DuckDuckGo（查询词） | DuckDuckGo |
| Obsidian 笔记 | 你本机的 Obsidian（Local REST API，默认关闭，需显式配置） | 只有你 |

**清除浏览器缓存会删除全部数据**——请定期到「设置 → 数据管理」导出备份（JSON 文件），换电脑时可一键导入恢复。

## 权限说明（为什么需要这些）

| 权限 | 用途 |
|---|---|
| 读取 B 站视频页面 | 获取当前视频信息（BV 号/分 P/时长）与播放位置，用于生成大纲、时间戳跳播与抽帧 |
| 请求 B 站字幕接口 | 拉取 UP 主字幕与 AI 字幕（AI 字幕需你已登录 B 站） |
| 请求模型服务商域名 | 把字幕片段/画面发给你自己配置的模型（DeepSeek / 阿里云 / 自定义端点，均为你主动配置） |
| 请求 duckduckgo.com | 问答时的公开资料检索 |
| 下载文件 | 导出大纲备份、下载 .md 笔记 |
| 本机 127.0.0.1:27123 | 连接你本机的 Obsidian Local REST API（仅当你显式配置时使用） |

自定义模型端点使用 `optional_host_permissions`：只在你在设置页保存该端点时才弹出授权申请，且精确到单个域名。

## 功能速览

- **字幕**：三级采集瀑布（UP 主 → AI → 手动粘贴），失败逐级降级；AI 字幕一键加标点顺句
- **大纲**：分块确定性生成，时间戳吸附到真实字幕边界；单章可带反馈重生成；章节/要点/笔记跳播
- **笔记**：整章/要点/时间点三种锚点；讨论串 + 请助教回答；大纲重生成后按时间自动归位，永不丢弃
- **导图**：章节重组为「阶段 → 概念」知识流程图，播放跟随高亮
- **问答**：划词解释 / 区间问答 / 自由追问；[mm:ss] 时间戳跳播；题目截图多模态作答
- **沉淀**：存入 Obsidian（已配置时）或下载 .md（未配置时自动降级，格式统一带来源与标签）
- **交换**：`vsc-outline` 开放格式导出/导入大纲与笔记（[格式文档](docs/EXCHANGE-FORMAT.md)）

## 常见问题

**生成要多久？** 大纲按视频长度分块，通常 20~90 秒；期间可切走，回来会续上。

**到底花多少钱？** 由你的模型按 token 计费。「设置 → 验证期报告」里有累计 token 与按官网价格的**费用估算**（估算值，以服务商账单为准）。

**生成失败了？** 常见原因：模型输出不稳定（换个更稳的模型）、Key 额度不足、代理拦截。「设置 → LLM 交互日志」能看每次请求详情（Key 已脱敏）。

**支持哪些视频？** B 站有字幕的教学视频效果最好。手机 B 站 App 不支持浏览器扩展。
